Go to https://developer.spotify.com/documentation/web-api/reference/get-information-about-the-users-current-playback
Open devtools network tab
Click "Try it" and click on the newly appeared request
Go to the "Headers" tab and scroll down to "Request Headers"
Find the "Authorization" header and copy the value (it should start with "Bearer ")
This is your access token copy it (without the "Bearer " part) and put it in the app
